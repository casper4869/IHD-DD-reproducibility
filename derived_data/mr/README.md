# MR derived-data map

- `manifest/`: full 15,703-row catalogue-to-analysis status record, outcome-specific schedules/summaries, primary 49-candidate screen, old-table cross-check, field dictionary, session information, and source/output hashes.
- `alternative_sets/`: Sets A-C, membership/status tables, counts, definitions, and checksums.
- `final_reporting/`: final 29-candidate Table 1 source, Figure 7 source/QA table, and session information.

These are exploratory aggregate-result reconstructions. The status manifest records automated technical scoping/scheduling and must not be described as manual phenotype inclusion/exclusion. The final 29-trait set applies the `finn-b-*` safeguard after the 49-trait exploratory screen. These files do not contain SNP-level instruments or harmonised data and cannot support unreported MR-Egger, weighted-median, pleiotropy, heterogeneity, leave-one-out, MR-PRESSO, Steiger, or F-statistic claims.
