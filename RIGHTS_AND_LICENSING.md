# Rights and licensing before public release

No repository-wide open licence has yet been selected. The authors must choose and verify licences before the Zenodo record is published.

- **Author-written code:** select an appropriate software licence after all co-authors/institutional requirements are checked.
- **Author-generated documentation and derived tables/figures:** select an appropriate content/data licence only for material the authors have the right to license.
- **Third-party GBD, IEU OpenGWAS, FinnGen/Risteys, boundary, PM2.5, and other provider material:** provider terms continue to apply. A repository licence must not be used to relicense third-party content.
- **Files not redistributed:** `data_access_protocol.md` supplies provider routes, query settings or known metadata, and local fingerprints where the authors do not hold clear redistribution rights.

Until a licence is added, public visibility alone does not grant broad reuse rights. Record the final code licence and data/content rights in the GitHub repository, GitHub Release, Zenodo metadata, and manuscript availability statement using consistent wording.
